The Printer Finally Answers

The office printer finally talks back. `main.ts` writes a single one-line comeback to
`/output/entry.txt` using only Node's built-in filesystem module.

## Run it

```sh
node --experimental-strip-types main.ts
```

The line is a single UTF-8 sentence of 72 characters, well inside the 240-character cap.
